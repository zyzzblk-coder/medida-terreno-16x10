# Medida de Terreno 16x10 metros

## Dimensões do Terreno

| Dimensão     | Valor     |
|--------------|-----------|
| **Comprimento** | 16 metros |
| **Largura**     | 10 metros |

## Cálculos

### Área
```
Área = Comprimento × Largura
Área = 16 m × 10 m = **160 m²**
```

### Perímetro
```
Perímetro = 2 × (Comprimento + Largura)
Perímetro = 2 × (16 m + 10 m) = 2 × 26 m = **52 metros**
```
